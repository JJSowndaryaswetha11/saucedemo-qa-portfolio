# SauceDemo Manual QA Testing Portfolio

##  Project Overview

This project demonstrates an end-to-end manual QA testing process performed on the SauceDemo web application.

The project covers requirement analysis, test planning, test scenario and test case design, test execution, defect reporting, retesting, regression testing, test reporting, and test closure.

The purpose of this project is to demonstrate practical manual testing skills through structured QA documentation and real application testing.

---

##  Application Under Test

**Application:** SauceDemo  
**URL:** https://www.saucedemo.com/

SauceDemo is a web-based e-commerce application that allows users to browse products, manage a shopping cart, enter checkout information, and complete orders.

---

##  Testing Objectives

- Verify the functional behavior of the application.
- Validate major end-to-end user workflows.
- Identify and document functional defects.
- Validate input fields and application behavior.
- Test different user accounts and their application behavior.
- Perform retesting of identified defects.
- Perform regression testing.
- Maintain professional QA documentation.

---

##  Testing Scope

The testing scope includes:

- Login and Authentication
- Logout and Security
- Products and Inventory
- Product Sorting
- Sidebar Navigation
- Dynamic Catalog
- Product Details
- Shopping Cart
- Checkout
- Order Completion
- Application State Management
- Footer and External Links

---

##  Test User Accounts

The application provides multiple user accounts with different behaviors.

The following accounts are considered during testing:

- `standard_user`
- `locked_out_user`
- `problem_user`
- `performance_glitch_user`
- `error_user`
- `visual_user`

Different accounts are used based on the functionality and behavior being tested.

---

##  Testing Approach

The project follows a structured manual QA workflow:

**Requirement Analysis → Test Planning → Test Design → Test Execution → Defect Reporting → Retesting → Regression Testing → Test Reporting → Test Closure**

Testing includes both positive and negative scenarios where applicable.

- Preconditions
- Steps to Reproduce
